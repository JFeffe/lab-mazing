# Publications GitHub

- Conserver le lien de jeu bien visible immédiatement sous le titre du README : https://jfeffe.github.io/lab-mazing/.
- Toute annonce de nouvelle version sur GitHub, notamment le corps d’une Release, doit commencer par le lien Markdown **Jouer au Labyrinthe de Folamour dans le navigateur**, avant les nouveautés et les instructions de téléchargement.
- Pour rédiger une annonce, reprendre `.github/RELEASE_TEMPLATE.md`, remplacer les indications entre crochets et conserver sa première ligne. Ce modèle est à copier explicitement ; GitHub ne l’applique pas automatiquement.
