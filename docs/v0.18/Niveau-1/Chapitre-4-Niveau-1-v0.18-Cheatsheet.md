## Bienvenue, vous habitez ici
Chapitre 4 / Niveau 1

### SPOILERS / VERSION 0.18

« Votre logement, votre emploi et vos opinions sont prêts. Votre arrivée, en revanche, n’a pas été autorisée. Veuillez démontrer votre présence. » — Folamour

Une gare en éventail : trois guichets au nord, un hall commun, puis deux labyrinthes de maintenance au sud. Les badges commandent les trois guichets ; le sas 111 mène aux dossiers et le sas 112 aux tubes.

### Parcours conseillé

Menu → Choisir un chapitre → Chapitre 4, puis choisir ce niveau. La transition depuis la mission précédente conserve les bilans. Le sac et le journal repartent à zéro à chaque nouveau niveau.

1. Ramasser la mallette 101 et l’installer au poste 203. Lire 201 et 202, puis résoudre 203 : Le droit d’exister. Le sas 111 s’ouvre.

2. Lire 301 et 302, puis résoudre 303 : La personne qui n’est pas arrivée. Le sas 112 s’ouvre.

3. Lire 401 et 402, puis résoudre 403 : Les tubes de régularisation. Rejoindre ensuite le passage 900.

Les notes secrètes 501, 502 et 503 sont facultatives. Leur lecture compte au bilan. Les 4 raccourcis demandent de marcher des deux côtés du mur ; la simple visibilité ne suffit pas.

### Commandes et sauvegarde

Clic ou toucher : marcher et examiner. WASD / ZQSD / flèches : marcher ; E : interagir ; I : sac ; J : journal ; M : carte. Aucune limite de temps. Les manipulations, mesures et programmes sont sauvegardés. Réinitialiser un essai restaure ses réglages sans rendre la mallette déjà installée. Après une simulation, modifier une commande exige un nouveau test.

### Indices graduels

Chaque poste propose une piste, une méthode, puis la solution complète. Ouvrir le panneau ne révèle rien automatiquement. Les indices consultés et les essais incorrects sont comptés au bilan.

## 01 / Le droit d’exister

Poste 203 : (17, 11). Mallette 101 requise.

Installer la mallette. Changer de badge ici, visiter chaque guichet, puis revenir. Lire A en résident, B en technicien et C en inspecteur ; certifier avec le badge inspecteur.

### 201 / Consigne 201 / (1, 11)

Le terminal 203 change votre badge. Résident ouvre A ; technicien ouvre B ; inspecteur ouvre C. Un seul badge actif. Les autres portes se ferment.

### 202 / Consigne 202 / (33, 11)

Lire les trois registres 210, 211 et 212, puis revenir au 203 en inspecteur pour certifier la présence. Les changements se font uniquement près du terminal. Les registres lus restent dans le journal.

### Visites physiques requises

Les registres restent acquis après réinitialisation du pupitre. Les changements d’accès se font uniquement près du pupitre ; revenez-y après chaque visite. Après validation du poste, les trois accès restent ouverts.

Accès | Position de la porte | Registre à visiter
--- | --- | ---
A | (7, 7) | 210 / (7, 3)
B | (17, 7) | 211 / (17, 3)
C | (27, 7) | 212 / (27, 3)

### Solution exacte depuis la réinitialisation

Depuis 203 : résident → lire 210 → retour ; technicien → lire 211 → retour ; inspecteur → lire 212 → retour. Choisir inspecteur et valider.

Chaque badge donne un accès différent. Aucun ne suffit seul. Les trois lectures restent acquises quand vous changez de badge.

Validation enregistrée. Le deuxième secteur est ouvert.

## 02 / La personne qui n’est pas arrivée

Poste 303 : (7, 23). Validation 203 requise.

Choisir le dossier, puis associer les trois preuves physiques : clé, quai, tampon. Un dossier anticipé ne prouve pas une arrivée.

### 301 / Consigne 301 / (1, 17)

Les trois registres du hall décrivent votre dossier : forme de clé, quai et tampon. Les cinq dossiers du pupitre sont complets. Un seul respecte les trois constats ensemble.

### 302 / Consigne 302 / (15, 33)

A : triangle / B / ajourné. B : carré / C / ajourné. C : triangle / C / anticipé. D : triangle / C / ajourné. E : carré / B / anticipé.

### Solution exacte depuis la réinitialisation

Dossier D ; clé triangle ; quai C ; tampon ajourné. Valider.

Le registre A impose triangle, B impose quai C, C impose ajourné. D est le seul dossier qui combine les trois.

Validation enregistrée. Le troisième secteur est ouvert.

## 03 / Les tubes de régularisation

Poste 403 : (27, 23). Validation 303 requise.

Régler A, B, C et D pour acheminer A → B → X et D → C → Y, avec les mêmes aiguillages. Le diagramme affiche les deux sorties possibles de chaque nœud. Tester puis valider.

### 401 / Consigne 401 / (19, 17)

Deux capsules partent de A puis D. Les aiguillages conservent le même réglage pendant les deux trajets. La capsule de A doit visiter B puis arriver à X. Celle de D doit visiter C puis arriver à Y.

### 402 / Consigne 402 / (33, 33)

Chaque aiguillage a deux sorties indiquées sur le schéma. Une boucle est refusée. Tester montre les deux trajets complets ; changer un réglage efface la certification du test.

### Sorties du réseau

Nœud | Sortie 0 | Sortie 1
--- | --- | ---
A | C | B
B | X | A
C | B | Y
D | A | C

### Solution exacte depuis la réinitialisation

A → B ; B → X ; C → Y ; D → C. Tester puis valider.

Fixer d’abord les arrivées : B doit viser X et C doit viser Y. A rejoint B ; D rejoint C.

Validation enregistrée. Le passage de fin de niveau est autorisé.
