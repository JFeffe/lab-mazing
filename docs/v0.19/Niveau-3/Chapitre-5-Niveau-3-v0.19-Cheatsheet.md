## 01 / Le quorum des désaccords

Poste 203 : (17, 17). Mallette 101 requise.

Choisir exactement trois copies, dont E. A signe seulement avec C ; C seulement avec A ; B seulement avec D ; D refuse E. Les exigences des copies absentes ne comptent pas.

### 201 / (1, 1)

Former un groupe de exactement trois signataires parmi A/B/C/D/E. E, l’auditeur, doit être présent. A exige C ; C exige A.

### 202 / (33, 1)

B exige D. D refuse tout groupe contenant E. Une exigence ne s’applique que si son auteur signe. Tous les présents doivent accepter le groupe.

### Solution depuis la réinitialisation

Inviter A, C et E. Laisser B et D absents. Valider.

E exclut D, donc B ne peut pas venir. Les trois places sont nécessairement A, C et E.

## 02 / La phrase que personne ne cite

Poste 303 : (7, 27). Validation du poste 203 requise.

Restaurer les six fragments : PROTÉGER en premier, puis les gens. Même lorsque précède leur avis change. Sans confondre vient ensuite ; un doute avec une faute termine. Tester la lecture complète.

### 301 / (1, 23)

Six fragments du mandat original. Une phrase commence par PROTÉGER. « les gens » suit ce verbe. « même lorsque » introduit « leur avis change ».

### 302 / (13, 33)

La réserve « sans confondre » vient après le changement d’avis. Elle se termine par « un doute avec une faute ». Utiliser chaque fragment une fois.

### Solution depuis la réinitialisation

PROTÉGER → les gens → même lorsque → leur avis change → sans confondre → un doute avec une faute. Tester et valider.

Les copies citaient seulement « protéger les gens ». Les quatre derniers fragments protègent aussi leur droit à l’incertitude.

Attention : modifier le réglage ou le programme invalide son dernier test. Relancer « Tester la procédure » avant de valider.

## 03 / Une permission de dire non

Poste 403 : (27, 27). Validation du poste 303 requise.

Rétablir une politique avec trois conditions ET. Cas autorisé : accord + constat + retour. Refuser les cas : silence seul ; prévision seule ; retour seulement promis ; aucun des trois. Les options affichent leurs effets sur le banc. Tester avant validation.

### 401 / (21, 23)

Une mesure originale doit satisfaire ensemble trois clauses : accord explicite, observation indépendante, possibilité de retour. Le silence, la prévision et un retour seulement promis ne suffisent pas.

### 402 / (33, 33)

Le banc présente cinq cas. Seul le premier satisfait les trois clauses. Les quatre autres manquent au moins une protection. Reconstruire les clauses, tester les cinq cas, puis approuver le droit d’arrêt.

### Solution depuis la réinitialisation

Accord explicite ; constat indépendant ; retour possible. Tester : seul le cas 1 est autorisé. Valider.

Une approbation explicite n’est pas un silence. Un constat n’est pas une prévision. Une issue praticable n’est pas une promesse.

Attention : modifier le réglage ou le programme invalide son dernier test. Relancer « Tester la procédure » avant de valider.
