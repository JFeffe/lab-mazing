### Collection et dossier

Collection : Rouage de prévoyance. Ramasser les dix souvenirs est facultatif. Le dossier compte les trouvailles par niveau et par chapitre ; une archive se révèle à 10, 25 et 50 trouvailles dans ce chapitre. Rien ne doit être dépensé ou remis à Folamour.

Une collection n’apparaît sur la carte du jeu qu’après découverte de sa case. Son cercle disparaît après ramassage. Le présent guide dévoile tous les emplacements. Le clic ou toucher permet de s’y rendre et de ramasser ; le bouton Ramasser et la touche E fonctionnent aussi.

La collection suit la sauvegarde de cette aventure. Dans le dossier, rejouer un niveau terminé conserve la collection et les bilans, mais recommence ses énigmes et remplace le niveau en cours après confirmation. Une nouvelle aventure remet le dossier à zéro.

## Énigmes et manipulations

### 203 — Horloges décalées

Régler les trois décalages. Les cadrans montrent le résultat immédiatement. Valider lorsqu’ils indiquent tous midi.

Piste : Pour chaque cadran, trouvez ce qui manque pour revenir à zéro.

Méthode : A : 2 + 10 ; B : 11 + 1 ; C : 3 + 9. Les multiples de douze reviennent à zéro.

Solution : Décalages A=10, B=1, C=9. Valider.

Depuis la réinitialisation : Décalages A=10, B=1, C=9. Valider.

A : 2 + 10 ; B : 11 + 1 ; C : 3 + 9. Les multiples de douze reviennent à zéro.

### 303 — Chronologie de l’incident

Ajouter les cinq cartes dans l’ordre causal. Retirer la dernière carte pour corriger. Tester la chronologie, puis valider.

Piste : Cherchez l’action qui n’a besoin d’aucun autre événement.

Méthode : La vanne est la cause initiale. Le verrouillage est la dernière conséquence.

Solution : Vanne → débit → température → alarme → verrouillage. Tester puis valider.

Depuis la réinitialisation : Vanne → débit → température → alarme → verrouillage. Tester puis valider.

La vanne est la cause initiale. Le verrouillage est la dernière conséquence.

### 403 — Prévention sans incident

Choisir les mesures puis simuler une coupure. Le test détaille alimentation, vanne, ventilation et alerte. Les essais ne modifient pas le laboratoire.

Piste : Corrigez les causes plutôt que l’avertissement.

Méthode : Alimentez la ventilation de secours et protégez la vanne. Laissez l’alarme audible, sans confinement qui étouffe la ventilation.

Solution : Secours OUI ; couper le son NON ; filtre OUI ; confinement NON. Tester puis valider.

Depuis la réinitialisation : Secours OUI ; couper le son NON ; filtre OUI ; confinement NON. Tester puis valider.

Alimentez la ventilation de secours et protégez la vanne. Laissez l’alarme audible, sans confinement qui étouffe la ventilation.

## Tous les repères et leurs conditions

### 201 — Le signal de midi — (33, 1)

Au signal de référence de midi, A affiche 2, B affiche 11 et C affiche 3. Les cadrans comportent douze positions : 0 représente midi. Appliquer un décalage fait avancer le cadran modulo douze.

### 202 — Règle de synchronisation — (1, 9)

Les trois cadrans doivent afficher 0 au même signal. Un décalage de 1 après 11 donne 0. On peut augmenter ou réduire les décalages ; il n’y a aucune course contre la montre.

### 203 — Horloges décalées — (17, 5)

À installer / remettre : Mallette de service

### 301 — Chaîne de causalité — (1, 13)

La vanne se ferme avant que le débit tombe. Sans débit, la température augmente. La température déclenche l’alarme. Le verrouillage automatique est une conséquence de l’alarme, pas sa cause.

### 302 — Rapport à l’envers — (33, 21)

L’imprimante classe les conséquences avant les causes. Reconstituez les cinq événements du premier au dernier. Aucune simultanéité dans cet incident.

### 303 — Chronologie de l’incident — (17, 17)

Ajouter les cinq cartes dans l’ordre causal. Retirer la dernière carte pour corriger. Tester la chronologie, puis valider.

À valider d’abord : 203 — Horloges décalées

Ouvre : 112

### 401 — Mesures autorisées — (33, 25)

Le secours fournit la ventilation si le circuit principal tombe. Le filtre empêche la poussière de coincer la vanne. Une alarme sonore doit rester active pour signaler une véritable panne.

### 402 — Le piège préventif — (1, 33)

Le confinement automatique ferme aussi la ventilation : le désactiver pour casser la boucle. Couper seulement le son ne résout rien. Tester les quatre mesures sur une panne simulée du circuit principal.
