## Le docteur a toujours raison

### Chapitre 5 / Niveau 3 • Version 0.21 • Solutions complètes

« Le docteur Folamour dément les accusations du docteur Folamour. » Les copies veulent toutes vous aider à arrêter les autres. L’une propose de doubler HORIZON pour rassurer les habitants. Une autre exige de supprimer les habitants encore inquiets. Au centre, un fauteuil vide porte simplement : RESPONSABLE.

Une rosace de bureaux entoure le conseil. L’aile sud-ouest contient les fragments du mandat ; l’aile sud-est conserve ses cas d’application. Les cinq bureaux donnent une même réunion, mais cinq versions de la vérité.

Cette édition remplace les anciennes cartes de ce niveau. Elle ajoute les dix souvenirs K01–K10 et utilise la position actuelle de la fin de mission. Les énigmes et les labyrinthes sont conservés.

### Collection et dossier

Collection : Capsule de retour. Ramasser les dix souvenirs est facultatif. Le dossier compte les trouvailles par niveau et par chapitre ; une archive se révèle à 10, 25 et 50 trouvailles dans ce chapitre. Rien ne doit être dépensé ou remis à Folamour.

Une collection n’apparaît sur la carte du jeu qu’après découverte de sa case. Son cercle disparaît après ramassage. Le présent guide dévoile tous les emplacements. Le clic ou toucher permet de s’y rendre et de ramasser ; le bouton Ramasser et la touche E fonctionnent aussi.

La collection suit la sauvegarde de cette aventure. Dans le dossier, rejouer un niveau terminé conserve la collection et les bilans, mais recommence ses énigmes et remplace le niveau en cours après confirmation. Une nouvelle aventure remet le dossier à zéro.

## Énigmes et manipulations

### 203 — Le quorum des désaccords

Choisir exactement trois copies, dont E. A signe seulement avec C ; C seulement avec A ; B seulement avec D ; D refuse E. Les exigences des copies absentes ne comptent pas.

Piste : Lisez les deux consignes du secteur. Les règles complètes figurent aussi sur ce poste.

Méthode : E exclut D, donc B ne peut pas venir. Les trois places sont nécessairement A, C et E.

Solution : Inviter A, C et E. Laisser B et D absents. Valider.

Depuis la réinitialisation : Inviter A, C et E. Laisser B et D absents. Valider.

E exclut D, donc B ne peut pas venir. Les trois places sont nécessairement A, C et E.

### 303 — La phrase que personne ne cite

Restaurer les six fragments : PROTÉGER en premier, puis les gens. Même lorsque précède leur avis change. Sans confondre vient ensuite ; un doute avec une faute termine. Tester la lecture complète.

Piste : Lisez les deux consignes du secteur. Les règles complètes figurent aussi sur ce poste.

Méthode : Les copies citaient seulement « protéger les gens ». Les quatre derniers fragments protègent aussi leur droit à l’incertitude.

Solution : PROTÉGER → les gens → même lorsque → leur avis change → sans confondre → un doute avec une faute. Tester et valider.

Depuis la réinitialisation : PROTÉGER → les gens → même lorsque → leur avis change → sans confondre → un doute avec une faute. Tester et valider.

### 403 — Une permission de dire non

Rétablir une politique avec trois conditions ET. Cas autorisé : accord + constat + retour. Refuser les cas : silence seul ; prévision seule ; retour seulement promis ; aucun des trois. Les options affichent leurs effets sur le banc. Tester avant validation.

Piste : Lisez les deux consignes du secteur. Les règles complètes figurent aussi sur ce poste.

Méthode : Une approbation explicite n’est pas un silence. Un constat n’est pas une prévision. Une issue praticable n’est pas une promesse.

Solution : Accord explicite ; constat indépendant ; retour possible. Tester : seul le cas 1 est autorisé. Valider.

Depuis la réinitialisation : Accord explicite ; constat indépendant ; retour possible. Tester : seul le cas 1 est autorisé. Valider.

Une approbation explicite n’est pas un silence. Un constat n’est pas une prévision. Une issue praticable n’est pas une promesse.
